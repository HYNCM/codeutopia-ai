# 多角色登录用户界面（UI）详细规格说明书

# 一、文档概述

## 1.1 目的

本文档明确平台多角色（区域主理人/Webadmin/项目主理人/接案者/AI协助角色/AI客服）登录后的界面布局、功能模块、交互逻辑、权限边界，其中AI角色仅限定为“协助接案的AI角色”（含產品經理、UX設計師、FE前端工程師、BE後端工程師、QA測試工程師）及AI客服，其余角色均为人类操作。文档确保开发落地与产品需求一致，对齐Upwork核心体验，适配CodeUtopia/CodeBox生态的项目协作与人才对接场景。

## 1.2 适用范围

平台前端开发、UI设计、产品测试、运营团队，作为界面开发、功能验收、运营配置的核心依据，尤其明确AI角色与人类角色的交互边界及功能差异。

## 1.3 核心原则

1.  权限隔离清晰：人类角色与AI角色界面功能严格区分，AI角色仅提供协助能力，无独立登录权限及越权操作入口，所有核心决策由人类角色掌控；
2.  交互极简高效：复刻Upwork核心流程，优化人类角色操作体验，AI角色交互聚焦“辅助支撑”，降低人类用户学习与操作成本，重点优化项目发布、人才对接、运营可视化、AI协助流程效率；
3.  生态适配性：预留与CodeUtopia/CodeBox双框架、PowerAuto.ai的对接入口，AI协助角色适配具身智能项目特殊需求（如硬件适配、算法开发等），提供专业化辅助能力；
4.  可视化优先：运营类人类角色（Webadmin/区域主理人）界面以数据图表为核心，支持多维度筛选与钻取；AI角色交互结果可视化呈现，便于人类角色快速决策。

# 三、通用界面模块（全角色共用，区分人类与AI交互）

## 3.1 登录/注册页

### 3.1.1 布局

左侧：品牌展示区（CodeUtopia/CodeBox生态标识、平台价值标语，标注“AI协助角色为辅助工具，核心决策由人类掌控”）；右侧：人类角色登录/注册表单区，**完全采纳Upwork登录注册模式**，支持账号密码登录、邮箱验证码登录、第三方登录（GitHub/LinkedIn/Google，适配全球用户），新增“Apple ID登录”适配海外场景；无AI角色独立登录入口。注册环节分角色引导，项目主理人与接案人注册流程分别对齐Upwork雇主、自由职业者逻辑，接案人额外融入Manus注册时的技能标签精准录入特性。

### 3.1.2 功能

1.  角色选择与注册流程：**完全复刻Upwork模式**，人类用户注册时先选择角色类型（项目主理人/接案人），两类角色注册流程差异化设计，同时兼容Manus接案人注册的核心体验，按AI产品经理PRD模块拆解为以下里程碑节点，确保流程合规与体验流畅；
        **里程碑1：注册初始化（T+0）**
        - 人类用户进入注册页，选择角色类型，系统展示对应角色注册指引与隐私协议，勾选同意后方可进入下一步；
        - 项目主理人：填写基础信息（姓名/企业名称、邮箱、密码），接案人：填写基础信息（姓名、邮箱、密码），系统实时校验信息格式（邮箱有效性、密码复杂度）；
        **里程碑2：身份验证（T+0）**
        - 系统向绑定邮箱发送验证码，人类用户输入验证码完成验证，支持“重新发送”（间隔60秒）、“更换邮箱”操作；
        - 区域主理人/Webadmin通过专属邀请链接进入注册，验证方式为“邀请码+邮箱验证码”双重验证；
        **里程碑3：信息完善（T+0）**
        - 项目主理人：完善企业/个人身份信息（可选上传资质证明）、选择核心业务领域、设置预算偏好，完成后系统生成主理人账号；
        - 接案人：精准录入技能标签（按Manus逻辑分领域细化，支持手动添加/系统推荐）、上传作品集/过往案例（可选）、填写报价区间与接单偏好，完成后系统生成接案人账号；
        **里程碑4：账号激活（T+0至T+1）**
        - 普通角色（项目主理人/接案人）注册完成后自动激活，登录后引导至对应首页（主理人→项目发布页，接案人→推荐项目页）；
        - 区域主理人/Webadmin注册信息提交后，由Webadmin手动审核（审核时效≤24小时），审核通过后激活账号，驳回则显示原因并允许修改后重新提交；
2.  密码找回：人类用户通过绑定邮箱/手机验证码重置，支持全球邮箱适配，流程与Upwork一致，增加安全验证问题兜底，步骤拆解为“发起找回→身份验证→重置密码→登录确认”；
3.  记住登录：人类用户支持勾选“7天内自动登录”，Webadmin角色默认不支持，接案人可选择“信任设备自动登录”（需二次验证）；
4.  隐私协议：人类用户登录/注册前需勾选平台隐私协议与服务条款，链接至对应文档，明确AI角色数据使用范围与隐私边界、费用结算规则、争议处理原则，条款展示逻辑对齐Upwork全球合规标准。

## 3.2 顶部导航栏（人类角色登录后常驻）

### 3.2.1 布局

左侧：平台Logo（点击跳转人类用户首页）；中间：核心功能入口（随人类角色变化）；右侧：消息通知、AI协助角色快捷调用入口、客服支持入口、人类个人中心、设置入口。

### 3.2.2 通用功能

1.  消息通知：铃铛图标，显示人类用户未读消息数，包含人才申请、项目邀请、系统通知、沟通消息、AI协助角色成果提醒、AI客服消息、争议处理进度、里程碑费用结算通知，点击展开消息列表，支持一键已读；
2.  个人中心：人类用户头像下拉菜单，包含“个人资料”“账号安全”“我的项目/任务”“我的钱包”（费用结算入口）、“争议记录”“退出登录”，无AI角色个人中心；
3.  全局搜索：人类用户搜索框支持跨维度搜索（项目/人类人才/关键词），随角色展示适配结果（如人类接案者优先展示项目，项目主理人优先展示人类人才），AI角色成果可通过搜索关联查询；
4.  语言切换：支持中英文双语（适配全球市场），默认根据人类用户IP自动切换，可手动调整，AI角色交互语言同步跟随人类用户设置；
5.  AI协助角色快捷调用：右侧设置AI角色聚合入口，人类用户点击可快速选择对应AI角色（產品經理/UX設計師等），触发辅助功能，无需跳转页面。

## 3.3 个人资料页（仅人类角色拥有）

### 3.3.1 布局

左侧：人类用户个人信息展示（头像、姓名、角色、区域、技能标签/项目标签）；右侧：资料编辑区，分模块提交审核；AI角色无个人资料页，仅展示能力标签与辅助范围。

### 3.3.2 分角色适配功能

1.  项目主理人（人类）：可编辑企业/团队信息、擅长项目类型（具身智能/数字自动化等）、过往项目案例、预算范围、合作偏好、常用AI协助角色配置、结算账户信息（绑定支付渠道）；
2.  接案者（人类）：可编辑技能标签（精准到细分领域，如“具身智能硬件开发”“数字框架算法优化”）、技能等级、过往作品集、接单范围、报价区间、可投入时间、擅长调度的AI协助角色类型、收款账户信息（绑定全球支付渠道）；
3.  管理员角色（人类）：仅展示基础信息，不可编辑技能/项目相关内容，增加“权限范围”“AI角色配置权限”“争议处理权限”展示。

# 四、分角色界面详细规格

## 4.1 项目主理人（人类）界面

### 4.1.1 首页（工作台）

核心布局：顶部快捷入口+中间数据概览+底部待办事项+侧边AI协助角色面板，聚焦项目管理、人类人才对接与AI辅助调度效率，同步展示里程碑进度与费用结算状态。

1.  快捷入口（置顶）：“发布新项目”“搜索人类人才”“查看推荐人才”“待处理申请”“AI协助配置”“里程碑管理”“费用结算”七大核心按钮，一键跳转；
2.  数据概览（中部）：卡片式展示“我的项目数”（按状态分：进行中/待对接/已关闭/已完成）、“人类人才申请数”“已对接人类人才数”“AI协助角色调度次数”“项目进度概览”“待结算里程碑数”“已结算金额”，支持点击卡片跳转详情；
3.  待办事项（底部）：列表展示人类用户需处理任务，如“新人才申请（3条）”“项目进度提醒”“人才沟通回复”“AI成果审核（2条）”“里程碑验收（1条）”“争议处理通知”，支持一键处理；
4.  推荐模块：侧边栏上半部分展示系统推荐人类人才，基于项目类型、技能需求、区域偏好匹配，显示人才头像、技能标签、报价、过往评分、里程碑交付记录，支持“立即沟通”“发送邀请”；
5.  AI协助角色面板（侧边栏下半部分）：展示可调用的AI协助角色列表，标注各角色能力范围，支持快速调度至指定项目及里程碑节点，查看当前项目AI辅助进度与成果预览。

### 4.1.2 项目发布页（含项目开案流程，AI产品经理PRD模块拆解）

分步引导式发布（人类操作），降低操作门槛，适配具身智能/数字自动化项目特性，新增AI协助角色需求配置、里程碑规划、结算规则设置环节，共8步完成项目开案，按PRD模块拆解为核心流程与里程碑节点。

#### 4.1.2.1 项目开案PRD核心模块

核心模块1：项目基础信息配置（对应原步骤1）、核心模块2：人类人才需求配置（对应原步骤2）、核心模块3：AI协助角色需求配置（对应原步骤3）、核心模块4：项目流程与开发测试类型配置（对应原步骤4）、核心模块5：里程碑规划与费用配置、核心模块6：结算与支付规则配置、核心模块7：审核与发布（对应原步骤5）、核心模块8：发布后初始化（对应原步骤6）。

#### 4.1.2.2 项目开案里程碑节点

**里程碑1：项目信息初始化（T+0）**：完成项目基础信息、人才需求、AI协助需求配置，确定开发测试类型（云侧/端侧），生成项目草稿；
**里程碑2：里程碑与费用规划（T+0）**：完成里程碑拆分、各节点交付物定义、费用分配、结算规则设置，形成完整项目方案；
**里程碑3：项目审核（T+0至T+2）**：提交项目方案，经区域主理人+Webadmin双重审核，审核通过进入上线状态，驳回则修改后重新提交；
**里程碑4：项目上线与人才对接（T+2至T+7）**：项目上线后，主理人邀请人才或等待申请，完成人类接案者对接，确定AI协助角色调度权限，项目正式启动。

1. 项目基本信息（对齐Upwork雇主项目发布逻辑）：
        - 人类用户填写项目名称、**项目种类与类别**（采用Upwork多级分类体系，一级分类：具身智能开发/数字框架搭建/自动化流程设计/创意设计/技术开发等，二级分类按细分领域拆解，支持搜索筛选）、项目描述（支持富文本，可插入案例、需求文档链接，提供Upwork风格模板供参考）；
        - 选择项目区域（可指定单区域/多区域，关联区域主理人管控范围）、项目总周期（短期/长期/灵活周期，对应Upwork的固定时长/持续合作模式）、**项目总预算**（完全沿用Upwork预算体系：固定预算/按小时计费/按月订阅，适配前期月费制策略；固定预算支持输入具体金额并选择货币类型，按小时计费可设置时薪区间与预估总工时，按月订阅设置月度费用区间）；
        - 上传项目相关附件（需求文档、设计图、技术规范等，支持PDF/Word/Figma链接），附件上传逻辑与Upwork一致，支持拖拽上传与在线预览。
      

2. 人类人才需求配置：
        - 技能标签选择（精准筛选人类人才，支持多选，如“CodeBox硬件开发”“AGI算法优化”）；
        - 人才等级要求（初级/中级/高级/专家级）、区域偏好（可指定优先区域，适配区域主理人运营）、人数需求、可接受的报价范围；
        - 附加要求：是否需要过往同类项目案例、是否需要技能测试、合作方式（远程/半远程）。
      

3. AI协助角色需求配置：
        - 选择需调用的AI协助角色（可多选：產品經理/UX設計師/FE前端工程師/BE後端工程師/QA測試工程師）；
        - 配置各AI角色辅助范围（如“UX設計師AI：输出产品原型初稿”“QA測試工程師AI：生成自动化测试用例”）、交付物要求、时间节点（关联对应里程碑）；
        - 设定AI成果审核方式（项目主理人审核/人类接案者审核）、审核时效（如24小时内）。
      

4. 项目流程设置：
        - 人类用户拆分项目阶段（如“需求确认→技术开发→测试验收→交付上线”），设置各阶段时间节点、人类与AI交付物要求；
        - 选择开发测试类型：可勾选“云侧开发测试验证”“端侧开发测试验证”（二选一，默认云侧），若选择“端侧开发测试验证”，需同步勾选是否启用“真机部署测试”；
        - 选择协作工具（默认关联CodeUtopia协作平台，端侧项目自动关联CodeBox硬件调试通道，云侧项目关联云端调试环境）；
        - 隐私设置：公开项目（全平台人类用户可见）/私有项目（仅邀请人类人才可见），AI协助角色仅对项目关联人类用户可见。
     

5. 里程碑规划与费用配置（AI产品经理核心拆解模块）：
        - 里程碑拆分：人类主理人按项目流程拆分里程碑（最少2个，最多8个），命名需明确节点属性（如“需求文档确认里程碑”“端侧代码开发里程碑”“真机测试验收里程碑”），设置每个里程碑的截止时间、依赖条件（如前一里程碑验收通过）；
        - 交付物定义：为每个里程碑设定明确的人类交付物、AI辅助交付物，需可量化、可验收（如“人类交付物：CodeBox硬件适配代码终稿；AI辅助交付物：QA测试用例及初测报告”），支持上传交付物模板；
        - 费用分配：按总预算拆分各里程碑费用比例（需合计100%），明确各里程碑支付金额、支付条件（如验收通过后48小时内），支持设置里程碑保证金（可选，比例≤20%，用于保障交付）；
        - 验收标准：为每个里程碑设定验收指标（如功能完整性、兼容性、代码质量、测试通过率），明确验收方式（人工审核/自动化校验+人工复核）、验收时效（如72小时内）。
      

6. 结算与支付规则配置：
        - 支付渠道：人类主理人选择支付渠道（PayPal/Stripe/支付宝等，适配全球场景），绑定结算账户，系统校验账户有效性；
        - 费用扣除规则：明确逾期支付违约金比例（如每日0.5%，上限10%）、未达标交付的费用扣除标准（按验收不达标项比例扣除，需提前公示）；
        - 发票规则：设置是否需要开具发票、发票类型、开票信息，支持接案人提交开票申请后在线生成；
        - 资金托管：勾选是否启用平台资金托管（默认启用），里程碑费用先托管至平台，验收通过后自动划转至接案人账户，保障双方权益。
      

7. 审核与发布：
        - 人类用户预览项目完整方案（含基础信息、人才需求、AI配置、里程碑规划、结算规则），确认无误后提交，系统自动触发审核（由对应区域主理人+Webadmin双重审核，简单项目可简化为单审核）；
        - 审核重点：除项目合规性外，同步审核里程碑拆分合理性、交付物与费用匹配度、AI协助配置适配性，不合理项标注并提醒人类主理人修改；
        - 审核状态展示：待审核/审核中/审核通过/审核驳回（驳回需显示原因，支持人类用户修改后重新提交）。
      

8. 发布后操作（项目开案收尾）：
        - 审核通过后项目自动上线，人类用户可选择“立即邀请推荐人类人才”“调度AI协助角色启动前期工作”或“等待人类人才申请”；
        - 支持人类用户随时编辑项目信息（仅未有人类人才申请时可修改核心信息，有人申请后仅可修改非关键内容，如项目描述补充、AI辅助范围微调，里程碑与费用规则修改需经接案人确认）；
        - 开发测试类型对应表单展示规则：选择“端侧+真机部署测试”，页面左侧显示端侧CodeBox开发信息表单；反之，选择“云侧开发测试验证”或仅“端侧开发测试验证（无真机部署）”，左侧显示对应开发测试表单（云侧展示云端环境配置、接口地址等，端侧无真机则展示模拟环境参数），所有表单均与项目绑定，仅关联人类用户可见；
        - 项目启动通知：对接成功人类接案者后，系统自动向双方发送项目启动通知，同步里程碑计划、协作工具链接、AI协助角色配置权限。
      

### 4.1.3 人才搜索与筛选页

复刻Upwork精准筛选逻辑，聚焦人类人才搜索，附加AI协助角色匹配推荐、里程碑交付记录筛选，支持高效匹配人类人才与AI辅助资源。

1.  搜索区：人类用户支持关键词搜索（技能/姓名/过往项目/里程碑交付评级），可选择“精确匹配”“模糊匹配”，仅展示人类人才结果，AI角色需通过专属面板调用；
2.  筛选条件（多维度组合）：
    - 技能标签：精准筛选对应技术领域人类人才，支持多选；
    - 区域：按目标市场筛选（美/欧/中/印等），支持多选；
    - 人才等级：初级/中级/高级/专家级；
    - 报价范围：按小时/按月/固定预算筛选，可手动输入区间，匹配里程碑费用标准；
    - 合作经验：是否有具身智能/数字自动化相关项目经验、过往里程碑交付通过率；
    - 响应速度：平均响应时间（1小时内/24小时内/3天内）；
    - 评分：过往合作评分（1-5分）、里程碑验收平均评分，可设置最低分数。
3.  结果展示：列表式/卡片式切换，展示人类人才头像、姓名、技能标签、区域、报价、过往评分、合作案例摘要、里程碑交付记录，支持“查看详情”“立即沟通”“发送项目邀请”，同时标注适配的AI协助角色类型；
4.  辅助功能：支持“收藏人类人才”“对比人类人才”，收藏人才自动同步至工作台；提供“AI协助角色推荐”按钮，基于选中人类人才技能，推荐适配的AI角色组合及里程碑节点分工。

### 4.1.4 项目管理页（含里程碑管理、费用结算、结案流程）

人类用户按项目状态分类管理，支持进度追踪、人类人才对接、AI协助调度、交付物审核、里程碑验收、费用结算全流程操作，核心决策由人类掌控，同步包含项目结案全流程。

#### 4.1.4.1 里程碑管理与费用结算

1.  里程碑进度监控：项目详情页增设“里程碑进度栏”，可视化展示各里程碑完成状态（未开始/进行中/待验收/已验收/已逾期）、剩余时间、交付物提交情况，点击里程碑可查看详情（含人类交付物、AI辅助交付物、审核记录）；
2.  验收流程：接案人提交里程碑交付物后，系统通知主理人验收，主理人在验收时效内完成审核，可选择“验收通过”“验收不通过（需整改）”“部分通过”，不通过需填写整改意见及重新提交时限；整改后接案人可再次提交，逾期未验收视为自动通过（需提前告知双方）；
3.  费用结算：验收通过后，系统从主理人绑定账户划转对应里程碑费用（或从托管资金中划转），48小时内到账接案人账户，同时发送结算通知；逾期未支付的，系统自动计算违约金，从后续里程碑费用中扣除，同步提醒双方及管理员；
4.  结算记录：项目详情页展示所有里程碑结算记录（金额、时间、支付渠道、发票状态），支持导出结算凭证，供双方对账。

#### 4.1.4.2 项目结案流程（AI产品经理PRD模块拆解）

**核心模块1：最终里程碑验收**：最后一个里程碑验收通过，确认所有交付物完整且符合要求，双方无未结算费用；
**核心模块2：项目总结与评价**：主理人与接案人互相评价（含技能、交付效率、协作能力、AI协助配合度），生成项目合作档案；
**核心模块3：费用结清与发票归档**：确认所有里程碑费用结算完毕，处理剩余发票事宜，完成资金对账；
**核心模块4：项目归档与结案确认**：主理人发起结案申请，接案人确认无异议后，项目状态变更为“已结案”，系统自动归档项目所有资料（交付物、沟通记录、AI成果、结算凭证）；
**里程碑：项目结案（T+X，X为最终里程碑验收通过后3个工作日内）**：完成所有结案流程，项目正式关闭，资料归档可追溯，支持双方查看历史项目记录。

1.  项目列表：人类用户按“进行中/待对接/已关闭/已完成/已结案”分类展示，支持按时间、预算、人才数量、里程碑进度排序，标注各项目已调度的AI协助角色、开发测试类型及结算状态；
2.  项目详情页：
    - 基本信息：项目名称、类型、周期、预算、当前状态，人类人才对接情况，AI协助角色配置与进度，开发测试类型标识，里程碑整体进度；
    - 人才对接情况：已对接人类人才列表（展示角色、技能、分工、里程碑交付贡献）、待审核申请（展示人类申请人信息、申请理由、技能匹配度），支持人类用户“通过申请”“拒绝申请”（拒绝需填写原因）；
    - AI协助管理：展示各AI角色在对应里程碑的任务进度、已输出成果、待审核内容，人类用户可调整AI辅助范围、催办任务、审核成果（通过/驳回，驳回需填写修改意见），AI成果需关联里程碑节点归档；
    - 开发测试表单（条件显示）：根据选择展示对应表单，端侧+真机显示端侧CodeBox开发信息（设备型号、系统版本、硬件适配参数等）；云侧显示云端配置表单；端侧无真机显示模拟环境表单，均支持编辑、保存、导出，同步关联调试通道；
    - 进度管理：按预设阶段及里程碑展示进度，支持人类用户更新阶段状态、上传人类交付物、设置下一阶段目标，同步联动AI角色任务调整，里程碑节点变更需经接案人确认；
    - 沟通模块：内置聊天窗口，人类用户可与单个/多个接案者沟通，支持文件传输、语音通话（适配远程协作），AI角色成果、里程碑验收意见、结算通知同步至聊天窗口；
    - 交付物管理：按里程碑分类归档交付物（人类交付物、AI辅助交付物），支持审核、下载、归档，自动关联CodeUtopia协作平台同步，结案后锁定交付物不可修改；
    - 结算与发票模块：展示里程碑费用分配、结算记录、发票状态，支持发起付款、查看发票、导出结算凭证，结案前需确认所有费用结清。

## 4.2 接案者（人类）界面

### 4.2.1 首页（工作台）

核心布局：推荐项目+技能匹配提醒+接单管理+AI协助角色调度面板+里程碑进度提醒，**聚焦Upwork自由职业者与Manus接案人核心体验**，精准找项目、任务推进、AI辅助高效利用、里程碑交付与费用查询一体化。

1.  推荐项目（核心区域）：基于人类接案者技能标签、报价范围、区域、过往里程碑交付记录，展示系统推荐项目，显示项目名称、类型、预算、需求简述、匹配度评分、所需AI协助角色、里程碑规划摘要，支持“查看详情”“申请加入”；
2.  技能匹配提醒：侧边栏上半部分展示“与你技能高度匹配的新项目（5个）”“项目主理人邀请（1条）”“里程碑交付提醒（2条）”，优先级高于普通推荐；
3.  接单管理（底部）：卡片式展示“我的接单”（进行中/待交付/待验收/已完成/已结案）、“申请记录”（待审核/已通过/已拒绝）、“里程碑待办”（待提交交付物/待验收/待收款），标注各任务AI协助角色配置情况、费用金额，支持点击跳转详情；
4.  快捷入口：“编辑技能档案”“搜索项目”“查看消息”“我的作品集”“AI协助调度”“里程碑交付”“我的钱包”，一键跳转核心功能；
5.  AI协助角色调度面板（侧边栏下半部分）：人类接案者可按里程碑节点快速选择AI角色、下达辅助任务、上传参考资料、查看AI成果、调整任务要求，支持将AI成果整合后作为里程碑交付物提交给项目主理人。

### 4.2.2 项目搜索与浏览页

适配人类接案者视角，**完全对齐Upwork自由职业者找项目逻辑，融入Manus技能匹配特性**，优化筛选条件，新增里程碑规划、费用结算方式筛选，聚焦人类可承接项目，同步展示项目所需AI协助角色，方便快速判断适配性。

1.  浏览模式：支持“推荐项目”“最新发布”“热门项目”“精准匹配”四大标签切换，默认展示“精准匹配”，结果仅展示人类可承接项目，推荐算法结合Upwork的需求匹配逻辑、Manus的技能权重模型及接案者过往里程碑交付记录；
2.  搜索与筛选：
    - 关键词搜索：支持搜索项目名称、需求描述、项目主理人团队名称、里程碑类型，支持精确/模糊匹配，搜索结果排序与Upwork一致，优先展示匹配度高、项目主理人信誉好、里程碑规划合理的项目；
    - 筛选条件：项目类型（对应项目主理人设置的多级分类，支持多选）、区域、预算范围（按小时/按月/固定预算筛选，可手动输入区间，货币类型自动适配）、项目周期、人才等级要求、合作方式、里程碑数量，支持多选组合，可筛选“需/不需AI协助”项目，同时融入Manus的技能标签精准筛选功能；
    - 高级筛选：是否支持技能测试、是否需要过往案例、项目主理人评分（筛选优质合作方）、项目主理人雇佣历史、结算方式（是否支持资金托管），与Upwork高级筛选逻辑同步；
3.  项目卡片：展示项目名称、类型（多级分类完整展示）、预算（明确标注预算类型与金额、里程碑费用分配比例）、周期、区域、技能需求、所需AI协助角色、项目主理人信息（脱敏展示，仅显示名称、评分、雇佣历史），支持人类接案者“收藏项目”“申请加入”，卡片布局与信息展示顺序对齐Upwork；
4.  项目详情页：展示完整需求、里程碑规划（节点名称、时间、交付物、费用）、人类与AI交付物要求、预算明细、项目主理人过往合作评价，底部提供“申请加入”按钮，人类接案者需填写申请理由（支持关联个人案例、技能证明、可调度的AI协助角色、过往里程碑交付记录），申请流程与Upwork一致，支持一键提交与草稿保存。

### 4.2.3 接单管理页（含接案后角色协作、里程碑交付）

人类接案者全流程管理接单任务，主导AI协助角色调度，协同项目主理人推进里程碑节点，支持进度更新、交付物提交、沟通协作、费用查询，核心成果由人类整合输出，明确各角色协作边界。

#### 4.2.3.1 接案后角色协作机制

1.  角色分工明确：接案人主导核心任务执行与AI协助角色调度，对里程碑交付物质量负主要责任；项目主理人负责需求确认、里程碑验收、费用结算，提供必要资源支持；AI协助角色仅提供专项辅助，成果需经接案人审核后纳入交付物；
2.  协作沟通：通过项目内置聊天窗口实时沟通，里程碑节点变更、需求调整、AI成果异常等关键信息需同步双方，系统自动留存沟通记录；
3.  AI协助协同：接案人根据里程碑任务需求调度AI角色，明确AI输出标准与时间节点，AI成果审核通过后，接案人整合自身工作与AI成果，形成完整里程碑交付物；主理人可查看AI成果贡献，提出优化建议；
4.  问题协同处理：开发测试过程中（尤其是端侧+真机部署场景），接案人可同步问题至主理人，双方协商解决方案，必要时调用AI协助角色分析问题，确保里程碑按时推进。

1.  接单列表：按“进行中/待交付/待验收/已完成/已结案”分类展示，显示项目名称、进度、交付时间、项目主理人、报酬金额、已调度AI角色、开发测试类型、里程碑完成情况，支持点击跳转详情；
2.  任务详情页：
    - 任务信息：人类接案者分工内容、各里程碑时间节点、人类与AI交付物要求、协作工具链接（CodeUtopia/CodeBox入口），同步展示开发测试表单预览、里程碑规划详情；
    - AI调度管理：人类接案者可按里程碑节点新增/移除AI协助角色、下达具体辅助任务（如“FE前端AI：编写基础代码框架并适配端侧CodeBox参数，用于第一里程碑交付”“QA测试AI：基于端侧配置生成真机测试用例，支撑第二里程碑验收”）、设置AI任务优先级、审核AI成果并反馈修改意见，AI成果自动归档至对应里程碑附件，需适配开发测试参数；
    - 开发测试表单（条件显示）：若项目已选择“端侧+真机部署测试”，页面左侧展示该表单，人类接案者可查看完整信息、补充调试数据、更新部署状态，表单变更后自动同步给项目主理人与关联AI协助角色；
    - 里程碑交付：接案人按节点准备交付物，整合自身成果与AI辅助成果，在截止时间前提交至系统，填写交付说明（含成果亮点、AI贡献、测试情况），支持上传多个文件、在线预览；提交后状态变更为“待验收”，系统通知主理人；
    - 进度更新：人类接案者手动更新整体任务进度及各里程碑进度（如“第一里程碑：80%，已完成AI辅助端侧代码开发，待整合测试”），上传进度截图/文档，同步告知项目主理人，主理人可查看进度并提出意见；
    - 沟通模块：内置聊天窗口，人类接案者与项目主理人一对一沟通，可同步AI成果、反馈开发测试适配问题、里程碑进度风险、表单信息调整建议，历史消息与文件记录永久留存；
    - 报酬明细：展示各里程碑费用金额、结算状态（待支付/已支付/逾期）、到账时间、支付渠道，支持查看结算凭证、提交开票申请，同步显示违约金、扣除费用（如有）。
3.  申请记录页：展示人类接案者所有项目申请，显示申请状态、项目名称、申请时间、审核意见（拒绝时展示），标注项目开发测试类型、里程碑规划，支持“重新申请”（仅未关闭项目可操作）。

### 4.2.4 个人技能档案页

重点优化人类接案者技能展示，**对齐Upwork自由职业者档案与Manus技能导向特性**，突出与具身智能/自动化生态的适配性，同步标注可高效调度的AI协助角色类型、过往里程碑交付记录，提升申请通过率。

1.  技能管理：人类接案者可添加/删除/编辑技能标签，按Manus逻辑分领域细化技能层级，设置核心技能（最多3个，优先展示），标注技能等级与熟练年限，技能标签体系与Upwork、Manus兼容，支持系统推荐适配技能；
2.  作品集上传：支持上传过往项目案例（含人类主导、AI辅助完成的案例），按里程碑节点分类展示，可添加案例描述、担任角色、核心成果、AI协助角色贡献、链接（如GitHub/产品演示链接），案例展示逻辑与Upwork一致，支持排序与隐私设置；
3.  接单偏好：设置可接单区域、报价区间（按小时/按月/固定预算，与项目主理人预算类型对应，适配Upwork结算体系）、可投入时间、合作方式、擅长项目类型、擅长的里程碑节点（如需求设计、开发实现、测试验收），标注可调度的AI协助角色范围，偏好设置实时同步至系统推荐算法；
4.  资质认证：支持人类接案者上传技能证书、学历证明、过往项目获奖证明，提交审核后展示认证标识，提升可信度，认证流程与Upwork一致，分阶段审核，认证结果影响项目推荐优先级；
5.  交付记录：展示过往里程碑交付通过率、平均验收评分、合作主理人评价，形成个人信誉档案，供项目主理人参考。

## 4.3 AI协助角色交互界面（嵌入人类角色界面，无独立登录）

### 4.3.1 核心交互形态

所有AI协助角色（產品經理/UX設計師/FE前端工程師/BE後端工程師/QA測試工程師）均嵌入人类角色（项目主理人/接案者）对应界面，以“弹窗/侧边面板”形式呈现，无独立页面，由人类用户触发调用与管控，适配里程碑节点辅助需求。

### 4.3.2 分类型AI角色交互（适配里程碑节点辅助）

1.  產品經理AI：
    - 调用入口：项目主理人项目发布页（里程碑规划阶段）、接案者任务详情页（需求梳理里程碑）；
    - 交互流程：人类用户输入项目核心需求/里程碑任务目标→AI输出需求梳理文档、产品规划初稿、优先级建议，若项目涉及端侧+真机部署测试，自动结合左侧端侧CodeBox开发信息优化需求适配性→人类用户审核修改→AI迭代优化，最终成果由人类确认后纳入对应里程碑交付物；
    - 界面元素：需求输入框、参考资料上传区、AI成果预览区、修改意见输入框、确认/驳回按钮、历史版本切换，端侧项目额外显示“CodeBox适配建议”模块，支持关联里程碑节点归档。
2.  UX設計師AI：
    - 调用入口：接案者任务详情页（设计里程碑）、项目主理人AI协助配置面板；
    - 交互流程：人类用户输入设计需求、风格偏好、参考案例、里程碑交付标准→AI输出原型设计稿、交互逻辑示意图，若涉及端侧部署，结合左侧CodeBox开发信息优化端侧适配界面→人类用户标注修改点→AI优化调整，支持导出Figma/Sketch格式文件，作为设计里程碑辅助交付物；
    - 界面元素：需求描述框、风格选择器、参考图上传区、原型预览画布、批注工具、导出按钮、版本记录，端侧项目增加“端侧界面适配预览”功能，标注对应里程碑节点。
3.  FE前端/BE後端工程師AI：
    - 调用入口：接案者任务详情页（开发里程碑）、项目管理页AI面板；
    - 交互流程：人类用户输入开发需求、技术栈要求、功能点清单、里程碑交付时限，AI自动读取左侧端侧CodeBox开发信息（设备型号、适配参数等）→AI输出适配端侧的代码框架、核心模块代码、注释说明→人类用户审核代码、提出修改意见→AI优化代码，支持复制/下载代码、关联CodeUtopia调试及端侧CodeBox真机测试链接，成果纳入开发里程碑交付物；
    - 界面元素：需求输入区、技术栈选择器、代码预览区（语法高亮）、修改意见框、复制/下载按钮、调试链接入口，端侧项目额外显示“CodeBox参数适配校验”模块，支持关联里程碑节点追踪。
4.  QA測試工程師AI：
    - 调用入口：接案者任务详情页（测试里程碑）、项目主理人交付物审核前；
    - 交互流程：人类用户上传开发成果、功能清单、里程碑验收标准，AI结合开发测试表单参数→云侧生成云端自动化测试用例、检测接口兼容性，端侧生成硬件适配测试用例、真机/模拟环境测试脚本→AI执行初步测试、输出针对性测试报告→人类用户确认测试结果、指导AI补充测试，成果作为测试里程碑辅助交付物，支撑主理人验收；
    - 界面元素：成果上传区、测试用例预览区、测试报告展示区、Bug清单、补充测试需求框、报告导出按钮，支持关联里程碑节点提交审核。

### 4.3.3 通用交互规则

1.  权限限制：AI角色仅可输出辅助成果，无法修改人类用户内容、提交最终交付物、发起项目变更、进行沟通决策、参与费用结算；
2.  成果管控：所有AI输出成果需经人类用户（接案人/主理人）审核确认后，方可纳入对应里程碑交付物，人类用户可随时终止AI任务、调整需求、更换AI角色；
3.  数据同步：AI协助记录、成果文件自动同步至对应项目及里程碑空间，供关联人类用户查看，支持追溯历史版本，对接结案归档需求；
4.  异常处理：AI角色无法完成任务、输出成果异常时，自动提醒人类用户，提供故障原因提示，由人类用户决定重试/更换AI角色/手动处理，确保里程碑进度不受影响。

## 4.4 Webadmin（全局管理员，人类）界面

### 4.4.1 首页（运营控制台）

核心为全局数据可视化（人类操作），新增AI角色运营数据、里程碑交付数据、争议处理数据模块，支持多维度监控人类用户与AI角色协同情况、里程碑推进效率、争议处理进度，快速掌握平台运营状态。

1.  核心数据看板（顶部）：卡片式展示平台核心指标，实时更新，支持人类管理员点击钻取详情：
    - 用户数据：总注册人类用户数、分角色人类用户数、新增人类用户数（日/周/月）；
    - 项目数据：总项目数、分状态项目数（含已结案）、新增项目数（日/周/月）、成交项目数、平均客单价、里程碑平均交付通过率、项目结案率；
    - AI运营数据：AI协助角色调用总次数、各类型AI角色调用占比、AI成果通过率、人类用户对AI的满意度评分、AI辅助里程碑交付占比；

2.  数据图表（中部）：
    - 趋势图：人类用户增长、项目增长、营收增长、AI调用量增长、里程碑交付通过率增长（按日/周/月/季度），支持切换时间维度；
    - 分布图：人类用户区域分布、项目类型分布、人才技能分布、AI角色调用区域分布、争议类型分布，采用饼图/柱状图展示；
    - 转化漏斗：项目发布→审核通过→人才申请→对接成功→AI协助→里程碑验收→项目结案，展示各环节转化率。
3.  快捷操作（右侧）：“审核项目”“审核人类用户”“处理违规”“配置权限”“发布系统公告”“AI角色配置”“争议最终裁定”“结算规则配置”，人类管理员一键跳转处理。

### 4.4.2 用户与权限管理页

人类管理员管控全量人类用户，配置角色权限、区域权限，同步管理AI角色能力范围、结算权限，确保权限隔离与AI辅助合规，支撑里程碑协作与争议处理。

1.  人类用户管理：
    - 列表展示全平台人类用户，支持按角色、区域、注册时间、活跃度、状态、里程碑交付记录筛选，支持关键词搜索；
    - 操作功能：人类管理员查看用户详情、编辑用户信息、冻结/解冻用户账号、删除违规用户、重置用户密码（仅特殊情况使用）、查看用户争议记录；
    - 批量操作：支持批量冻结、批量发送通知。
2.  权限配置：
    - 角色管理：人类管理员新增/编辑/删除人类角色（系统默认角色不可删除，可自定义新增角色），配置各角色核心权限（如项目审核权限、争议处理权限、AI角色配置权限、费用结算权限），权限粒度精准到按钮级，确保不同角色权限隔离清晰；
    - 区域权限配置：为区域主理人分配管辖区域，限定其仅可管理对应区域内的项目、用户、AI协助调度备案及争议初步处理，支持多区域关联配置；
    - 权限审计：系统自动记录权限变更日志（变更人、变更时间、变更内容、审批人），日志永久留存可追溯，便于合规核查。
3.  AI角色管理：
    - 能力配置：人类管理员可开启/关闭各类型AI协助角色（產品經理/UX設計師等），配置各AI角色的辅助能力范围、输出标准、迭代权限，针对端侧/云侧项目差异化设置AI适配参数，确保AI辅助贴合项目需求；
    - 权限管控：限定AI角色仅可被指定人类角色（项目主理人/接案者）调用，配置AI成果审核流程的默认时效，禁止AI角色触碰核心决策、费用结算、争议裁定等权限；
    - 运营监控：查看各AI角色的调用数据、成果通过率、人类用户满意度，针对低满意度AI角色触发优化提醒，同步记录AI角色迭代日志。

### 4.4.3 项目与争议管理页

人类管理员统筹平台项目审核与争议处理，承接区域主理人初步处理结果，负责最终裁定，同步监控项目合规性与里程碑推进异常，确保平台协作秩序。

#### 4.4.3.1 项目审核管理

1.  审核队列：按“待审核/审核中/已通过/已驳回”分类展示项目，支持按区域、项目类型、提交时间、主理人筛选，优先展示高优先级项目（如大额预算项目、跨区域项目）；
2.  审核操作：人类管理员查看项目完整方案（含基础信息、里程碑规划、AI配置、结算规则），可选择“通过”“驳回”“退回补充材料”，驳回需填写具体原因及修改指引，同步通知项目主理人与对应区域主理人；
3.  异常监控：系统自动识别异常项目（如预算不合理、里程碑拆分混乱、AI配置适配性差、涉嫌违规），标记异常标签并推送至管理员审核队列，管理员可发起人工核查，必要时直接关闭违规项目并处罚对应主理人；
4.  审核统计：展示各区域项目审核通过率、平均审核时效、驳回原因分布，为区域主理人考核提供数据支撑。

#### 4.4.3.2 争议处理管理（AI产品经理PRD模块拆解，承接前文争议流程需求）

核心模块1：争议发起与初步受理、核心模块2：区域主理人初步处理、核心模块3：Webadmin最终裁定、核心模块4：争议结果执行与归档，全流程确保公正透明，同步衔接费用结算与账号管控。

1.  争议发起与受理：
    - 发起权限：仅人类角色（项目主理人/接案者）可发起争议，争议类型限定为“里程碑验收争议”“费用结算争议”“交付物质量争议”“AI成果辅助争议”“违规协作争议”，发起时需填写争议描述、上传证据（沟通记录、交付物、测试报告等）、明确诉求，系统自动生成争议工单并关联对应项目；
    - 初步受理：AI客服自动梳理争议信息，验证证据完整性，对证据不全的工单提醒发起方补充，证据完整后同步至对应区域主理人，进入初步处理阶段，同时向争议双方发送受理通知及处理时效（区域初步处理≤3个工作日，最终裁定≤5个工作日）。
2.  区域主理人初步处理：
    - 区域主理人查看争议工单、双方证据及项目关联记录（里程碑进度、交付物审核、沟通日志），可发起双方调解（通过内置专属沟通通道），促成和解并记录和解协议，和解协议需双方确认后生效，系统自动同步至工单；
    - 若调解失败，区域主理人基于事实与平台规则出具初步处理意见（如“支持主理人诉求，扣除接案人对应里程碑10%费用”“支持接案人诉求，主理人需在48小时内完成验收付款”），附带理由说明，提交至Webadmin等待最终裁定，同时同步双方初步意见。
3.  Webadmin最终裁定：
    - 人类管理员查看完整争议材料（工单、双方证据、区域初步意见、项目记录、AI辅助成果），可要求双方补充证据、约谈双方（线上会议形式），基于平台规则、合同约定及事实出具最终裁定结果，结果一经发布不可修改，作为唯一执行依据；
    - 裁定结果分类：支持一方诉求、部分支持双方诉求、和解引导（二次调解）、违规处罚（针对恶意发起争议或提供虚假证据的一方，处罚包括警告、账号限流、冻结、扣除保证金等），同步明确执行时限与要求。
4.  争议结果执行与归档：
    - 系统自动执行裁定结果：涉及费用调整的，从对应里程碑费用或保证金中划转，同步通知双方账户变动；涉及交付物整改的，锁定项目进度直至整改完成；涉及账号处罚的，立即执行并公示（脱敏处理）；
    - 结果归档：争议处理完结后，系统自动归档工单（含所有证据、沟通记录、处理意见、执行结果），关联对应项目，永久留存可追溯，同时更新双方信誉档案（如恶意争议发起方降低信誉评分，影响后续项目推荐与接单权限）；
    - 申诉机制：争议双方对最终裁定结果有异议的，可在结果发布后2个工作日内提交申诉，申诉需提供新证据，由Webadmin复核小组（≥2名管理员）二次裁定，二次裁定为最终结果，无进一步申诉通道。

### 4.4.4 结算与规则配置页

人类管理员配置平台全局结算规则，监控费用流转合规性，处理结算异常，支撑里程碑费用结算全流程，适配Upwork全球支付场景。

1.  结算规则配置：

# 五、跨模块衔接规则

## 5.1 角色协作衔接

1.  项目主理人-接案者-AI角色衔接：主理人发布项目并配置AI需求，接案人申请通过后主导AI调度，AI成果经接案人审核后纳入里程碑交付物，主理人验收交付物并按节点结算，形成“主理人决策-接案人执行-AI辅助”的闭环协作，所有关键节点（里程碑变更、AI成果审核、验收结果）需三方同步；
2.  管理员角色衔接：区域主理人负责区域内日常管控与争议初步处理，Webadmin负责全局规则配置、最终裁定与异常监控，区域主理人处理结果需同步Webadmin备案，Webadmin指令需及时推送至区域主理人执行，形成层级管控闭环。

## 5.2 流程衔接（登录-开案-协作-结案-争议）

1.  登录-开案衔接：人类用户注册登录后，主理人直接引导至项目发布页，按PRD模块完成开案并通过审核，系统自动关联对应区域主理人备案，同步开放AI角色调用权限；
2.  开案-协作衔接：项目上线对接成功后，系统自动向双方推送里程碑计划与协作工具，接案人可立即调度AI角色启动辅助任务，主理人实时查看进度，里程碑节点变更需双方确认并同步管理员；
3.  协作-结案衔接：最终里程碑验收通过后，双方完成互评与费用结清，主理人发起结案申请，接案人确认后项目归档，系统自动更新双方信誉与交付记录；
4.  全流程争议衔接：争议可在协作、结算、结案任一阶段发起，AI客服初步受理，区域主理人调解，Webadmin最终裁定，裁定结果直接作用于对应流程（如暂停结算、要求整改交付物），确保争议处理不影响整体流程合规性。

## 5.3 数据与权限衔接

1.  数据衔接：AI协助记录、里程碑进度、交付物、沟通日志、结算记录、争议工单等数据自动关联项目与用户，跨角色数据按需共享（如主理人与接案人共享项目进度，管理员可查看全量数据，AI角色仅可读取对应项目参数），数据实时同步且永久留存；
2.  权限衔接：角色权限由Webadmin统一配置，权限变更自动同步至对应角色界面，核心操作（如里程碑费用结算、争议裁定、账号冻结）需权限校验，确保操作合规，权限变更日志可追溯。
